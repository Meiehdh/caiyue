# 彩阅（v1.8）

## v1.8：首页导出/导入备份 + 长按改为 1.5 秒

### 1. 首页就能看到的「导出备份 / 导入备份」

书架顶部新增两行，和「我的收藏」并列：

- **⬆ 导出备份**：书库 + 收藏 + 染色规则，导出为一个 zip
- **⬇ 导入备份**：从另一台设备的备份文件恢复

点一下弹出系统文件选择器（和浏览器书签导出/导入一样）：

- 导出：选择保存位置（默认文件名 `CaiYue-backup-年月日-时分.zip`）
- 导入：选中 zip 即可，导入完回到书架

### 备份里有什么

| 内容 | 说明 |
|---|---|
| `data/books.json` | 书库列表、所在文件夹、阅读进度 |
| `books/*.txt` | 书籍正文本身（换设备也能直接读） |
| `data/favorites.json` | 收藏与点评 |
| `data/rules.json` | 染色规则（含“仅当前书”的规则） |
| `data/folders.json` | 文件夹、私密文件夹（含密码哈希） |
| `data/bookmarks.json` | 书签 |
| `prefs.json` | 每本书的字号/行距/边距/背景/模式 |

### 导入时怎么合并

按 id 去重，不会重复也不会覆盖已有数据：

- 新书追加，旧书保留原有阅读进度
- 收藏、规则、书签、文件夹只补缺
- 阅读设置只补没有的那几本
- 书籍文件路径会改写成当前设备的路径

实测：清空应用数据后导入 41 MB 备份 → 恢复 22 本书 + 22 个正文文件 + 染色规则。

### 2. 长按时间 3 秒 → 1.5 秒

之前 3 秒偏长。现在按住约 1.5 秒弹出「选择文字」，实测 1.6 秒触发；短按仍不会误触。

## 已知问题

- 备份包含全部书籍正文，书多时 zip 会比较大（几十 MB）
- 私密文件夹密码以哈希形式导出，导入后需用原密码打开
- EPUB 仍为纯文本提取
