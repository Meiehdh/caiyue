# 彩阅（CaiYue）

一个本地电子书阅读器：支持 TXT / EPUB，能按自定义规则给文字上色，适合长篇小说阅读与整理。

## 功能

**阅读**
- 导入 TXT / EPUB（可多选），自动识别 UTF-8 / GBK，按「第X章」分章
- 两种阅读模式，**一书一配置**：
  - 翻页模式：原生 `StaticLayout` 精确分页，点按/滑动翻一整页
  - 上下滚动：`RecyclerView` 按章回收，几百万字也不卡
- 字号 13–30、行距 1.30–2.40、页边距 8–40dp 实时调节
- 界面配色：5 种预设底色 + 十六进制自定义，文字颜色随背景明暗自动反转
- 沉浸全屏，点屏幕中间呼出/收起菜单
- 翻页模式显示「当前页/全书总页数」；滚动模式实时显示**全书百分比**（两位小数）

**上色**
- 染色规则：关键词或正则，命中处上色 / 加粗，支持「全部书籍」或「仅当前书」
  - 重叠时按「起点靠前、同起点最长」裁决，例如「魔法少女」红 + 「魔法」蓝可共存
- 双引号对话自动上色：整句引号内容染色，句中关键词仍保留自己的颜色，颜色可自定义

**整理与收藏**
- 长按 **3 秒** 选择文字（可拖两端圆点跨段），复制 / 收藏 / 收藏并点评
- 书签：记录章节与位置，可跳转、可删除
- 收藏按「收藏自《书名》」分组，原书删除后收藏仍保留；点评可随时编辑
- 文件夹：自由命名，可把书移动进去；私密文件夹需 **4 位数字密码** 才能打开

**其他**
- 随机取色：一次给出 5 个随机颜色及十六进制码，点击即复制，可「换一批」

## 安装

1. 在 [Releases](../../releases) 下载最新 APK
2. 传到手机，允许「安装未知来源应用」，安装即可
3. 要求 Android 8.0 及以上

## 说明

- 这是 **debug 签名** 的安装包，适合自己使用与备份，不能直接上架应用商店
- EPUB 目前走「提取纯文本」路径，原书图片与排版会丢失
- 密码用于本地防误触，书籍文件并未加密
