# 彩阅（v1.7）

## v1.7：修复「同一行在两页重复」+ 独立上下边距 + 数值显示

### 1. 分页重复行的根因

翻页绘制时，整章排版只画一次，靠 `clipRect` 裁出当前页：

```
translate(x, 上边距 - 本页首行的 lineTop)
clipRect(左, 上边距, 右, 上边距 + 本页末行的 lineBottom)   ← 错在这里
```

`translate` 已经把「本页首行」移到了页面顶部，所以裁剪底边必须再减去首行的 `lineTop`。少减这一下，裁剪框比页面实际高度大了「首行的位置」，一页会多画出下一行甚至下几行；下一页又从那一行开始画，视觉上就是**同一行出现两次**，行距越大越明显。

修正后：

```
clipRect(左, 上边距, 右, min(页底, 上边距 + 末行 lineBottom - 首行 lineTop))
```

同时对分页起点做了强约束（严格递增、每页至少一行、末行完整落在裁剪区内），任何字号/行距/边距组合下，同一行只会出现在一页里。

### 2. 上边距 / 下边距独立

- 页边距：左右
- 上边距 / 下边距：上下各自独立
- 三者一起参与分页计算，内容不会被状态栏或底栏压住

### 3. 所有调节项显示具体数值

字号 `21sp`、行距 `1.75 倍`、页边距 `18dp`、上边距 `34dp`、下边距 `34dp`，拖动时实时更新。

## 实机验证

用截图里的那本书（幽灵小姐的百物语，21sp / 1.75 倍 / 上下边距 34dp）逐页翻：

- 修复前：第 6 页末尾「附一张纸条——"饭里有毒！"。」在第 7 页开头重复出现
- 修复后：上一页末行「这就有点吓人……不，吓鬼了呢……」→ 下一页直接是「第2章 鬼生无趣」，**无重复、无缺行**
- 页面底部不再出现半个字
